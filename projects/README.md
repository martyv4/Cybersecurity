# Projects

This folder contains larger, multi-file cybersecurity projects and research work.

## Structure

Each project lives in its own subfolder:

```
projects/
└── <project-name>/
    ├── README.md      # Overview, architecture, and usage
    └── src/           # Source files
```

## Planned Projects

| Project | Description | Status |
|---------|-------------|--------|
| Network mapper | Full network discovery and visualization tool | Planned |
| Vulnerability scanner | Automated service version and CVE checker | Planned |
| Password auditor | Dictionary and rule-based password strength tester | Planned |

## Adding a New Project

1. Create a subfolder: `<project-name>/`
2. Add source files in a `src/` directory
3. Add a `README.md` with overview, architecture details, and usage instructions
