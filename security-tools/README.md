# Security Tools

This folder contains standalone security utilities and helper scripts.

## Structure

Each tool lives in its own subfolder:

```
security-tools/
└── <tool-name>/
    ├── README.md      # Description, usage, and examples
    └── <tool>.py      # Main script
```

## Planned Tools

| Tool | Description | Status |
|------|-------------|--------|
| Hash identifier | Detect common hash types | Planned |
| Log analyzer | Parse and flag suspicious log entries | Planned |
| Subdomain enumerator | Brute-force DNS subdomains | Planned |

## Adding a New Tool

1. Create a subfolder: `<tool-name>/`
2. Add the main script(s)
3. Add a `README.md` with description, usage, and examples
